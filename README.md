# Insurance Cost Prediction

This project analyzes a dataset of medical insurance charges and uses predictive modeling to estimate the cost of insurance for individuals based on demographic and behavioral features.

## 📌 Objectives
- Predict insurance charges using demographic data
- Compare model performance (Linear Regression vs Random Forest)
- Provide actionable insights from data

## 📊 Dataset
- Source: Public insurance dataset (1338 rows)
- Features: age, gender, BMI, children, smoker, region, charges
- Target: `charges` (total medical costs)
